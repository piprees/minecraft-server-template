# What apply.sh does, and what it leaves

Measured on a fresh clone of the branch with the kit committed: `cutover/apply.sh`, then `./scripts/test-scripts.sh --quick` (exit 0; 460 unit tests OK), `python3 -m pytest -q scripts/tests mods/custom-dimensions-client-26/scripts` (544 passed, 4 skipped), and in `mods/custom-dimensions-26` `./gradlew build` (core 671, compiler 389, server 59 tests, no failures) and the companion's build (35 tests).
