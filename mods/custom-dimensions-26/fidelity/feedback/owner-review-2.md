## Rulings

- **The description comes first.** Every choice in a definition (sky, light, materials, terrain shape, biomes, mobs, structures) must be traceable to a phrase of its description or its 1.21.1 source; whatever contradicts the description goes, however well it measures.
- **Structures are curated per dimension.** No generic scatter: mineshafts, woodland mansions and other overworld structures appear only where the description wants them. A dimension that says nothing was built has nothing built.
- **Too much cherry** across the pack; cherry and other signature biomes only where a description asks for them.
- the_aviary keeps the original paradise_lost character: dramatic cliffs and peaks, temples and towers.
