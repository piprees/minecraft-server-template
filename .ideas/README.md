Findings and proposals that aren't yet code. Not a changelog and not documentation: everything here is something **still to action**. When an item ships, delete it from here — the repo's docs are where finished things get described.

## Where finished work went

The 15 skill-proposal briefs that lived here were built out into `.claude/skills/` and reviewed; they've been deleted rather than left as duplicates of the thing they describe. The skills are the artefact now.

## Conventions

- One file per topic, named for the thing it's about.
- Lead with status. If someone can't tell in ten seconds whether an item is open, the file has failed.
- Cite problems by their `TROUBLESHOOTING.md` id (`#t14`) rather than restating them.
